# 🧠 AI-Based MCQ Generator

An AI-powered **Multiple Choice Question (MCQ) Generator** that automatically generates high-quality multiple-choice questions from textual content using **Natural Language Processing (NLP)** techniques. The system extracts important information from the input text, identifies key concepts, and creates meaningful questions with multiple answer options, reducing the manual effort required for quiz creation.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/FlameDash25/MCQ_GEN.git
```

## Navigate to Project

```bash
cd MCQ_GEN
```

## Create Virtual Environment

```bash
python -m venv venv
```

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
python app.py
```

Open:

```
http://127.0.0.1:5000/
```
